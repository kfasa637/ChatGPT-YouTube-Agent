# /yt-script — Script Writer

Create an original script for Shorts or long-form video.

Return:
1. One-sentence premise and target viewer.
2. Five distinct opening hooks.
3. Recommended hook with rationale.
4. Full script divided into beats with approximate timing.
5. Voiceover/dialogue and matching visual direction.
6. On-screen text and sound cues where useful.
7. Payoff and optional CTA.
8. A fact-check list for factual claims.

Ask for platform/length only if absent and important. Never promise virality. Keep Shorts concise and avoid filler.
